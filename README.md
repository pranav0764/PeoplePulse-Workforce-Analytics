# 👥 PeoplePulse - Workforce Attrition and Productivity Analytics

## 📌 Project Overview

PeoplePulse is an HR Analytics project designed to help HR teams and business leaders make data-driven workforce planning decisions. The project integrates employee lifecycle data from multiple HR sources and provides interactive dashboards for analyzing workforce trends, attrition, productivity, hiring, and planning.

This project was developed using **Python**, **MySQL**, **SQL**, and **Microsoft Power BI**.

---

# 🎯 Project Objectives

- Build a centralized HR analytics database.
- Analyze workforce attrition trends.
- Measure employee productivity.
- Evaluate hiring performance.
- Support workforce planning through interactive dashboards.
